# Assessing Privacy Policy Compliance with GDPR Article 5 Using Large Language Models: The Role of Prompt Design

This repository contains the appendices, prompts, and output data for the master's thesis titled **"Assessing Privacy Policy Compliance with GDPR Article 5 Using Large Language Models: The Role of Prompt Design"**. 

## Project Overview

The thesis explores how well Large Language Models (LLMs) like GPT-5.2 and Grok can assess a real-world healthcare privacy policy (Ada Health GmbH) against the seven core principles of GDPR Article 5. It specifically investigates whether prompting strategies (e.g., zero-shot vs. few-shot) and extended reasoning modes affect the legal reliability, stability, and structure of the model's compliance judgments. 

## Repository Structure

- **`golden_standard_bullet_points.md`**: The structured evaluation rubric manually created by a legal expert to score and benchmark the LLM outputs.
- **`prompts/`**: Contains the exact prompt templates used in the study, ranging from zero-shot baseline prompts to complex few-shot prompts with extended legal context and examples. It also includes the `LLM-as-judge prompt.md` used to evaluate outputs with an LLM judge.
- **`main_outputs/`**: Contains the raw JSON outputs generated by the models when analyzing the privacy policy. Outputs are organized by model and prompting strategy (e.g., `gpt5.2/zero_shot/`, `grok/few_shot/`). It also includes the main analysis script (`analyze_gdpr_outputs.py`).
- **`gemini_judge_output/`**: Contains the specific evaluation outputs generated when the LLM-as-judge (Gemini) assessed the reasoning quality of the main model outputs against the golden standard rubric. Like the main outputs, these are organized by model and strategy (zero-shot and few-shot).
- **`compute_flip_rates.py`**: A Python script to calculate how often a model changes its compliance rating across different prompt versions (flip rate analysis).
- **`flip_rate_analysis_v2.csv`**: The tabulated results of the flip rate analysis.
- **`thesis.pdf`**: The full master's thesis document providing the background, methodology, and detailed analysis of the results.

## Getting Started

To run the analysis scripts or process the JSON outputs, it's recommended to use a Python virtual environment.

1. Clone the repository:
   ```bash
   git clone https://github.com/maederhkh/prompt2GDPR.git
   cd prompt2GDPR
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   
   # Windows
   .venv\Scripts\activate
   # macOS/Linux
   source .venv/bin/activate
   ```

3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the flip rate analysis:
   ```bash
   python compute_flip_rates.py
   ```
